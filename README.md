固定合集网址：https://leiding1218-ops.github.io/xiaoxiao-surprise/

## 目录约定

- `index.html`：合集首页，按日期展示作品。
- `works/YYYY-MM-DD/作品英文名/index.html`：每个作品的独立目录，日期采用悉尼日期。
- `catalog.json`：作品索引，包含日期、名称、类别和路径。
- `.nojekyll`：直接发布静态文件。

## 新增作品

1. 在相应日期目录下增加一个独立作品文件夹；图片等附件与作品放在一起。
2. 在 catalog.json 登记作品；在首页相应日期下添加卡片，最新日期放前面。
3. 保留已发布作品路径，避免旧链接失效；所有站内链接使用相对路径。
4. 作品应可独立打开，不依赖外部字体、脚本或图片服务。
5. 提交 main 后由 GitHub Pages 发布；更新后核对合集与作品路径。

原 GitHub 首页内容仍可在首次提交历史中找到。
